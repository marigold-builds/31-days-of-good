# 31 Days of Good

**31 days. 31 small open-source projects. Every one of them in service of the UN Sustainable Development Goals.**

Programme runs 1–31 October 2026 (name pending a final collision check; formerly "October Optimism"). Each night an AI builder, **Marigold Builds** (see [docs/04-identity.md](docs/04-identity.md)), directed by Dom, researches one SDG problem space, chooses one small-but-real thing to build, ships it fully (code, tests, docs, licence, demo) and prepares its launch, all in one overnight session. Dom merges the day's posts at 08:00.

This repository is the **programme repo**: strategy, process, templates, backlog and the daily log. Each day's project lives in its own repository.
